# OutCast

Voice dictation with AI clean-up, for Android and Windows. Speak in any app, and clean, ready-to-send text is typed where your cursor is.

**Features and downloads: https://stephenh678.github.io/outcast-releases/**

This repository holds the releases both apps download and update from: `OutCast-X.Y.Z.apk` for Android and `OutCast-Setup-X.Y.Z.exe` for Windows, in each [release](https://github.com/stephenh678/outcast-releases/releases). The web page is in `site/` and is published by `.github/workflows/pages.yml`.
